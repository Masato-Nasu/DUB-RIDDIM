# DUB RIDDIM

**一曲作れるDUB専用リズムマシーン。**

[OPEN APP](https://dub-siren.sunny-seed-0354.chatgpt.site)

ドラム、ベース、スカンク、バブルを組み合わせ、音符を編集してDUBを作るブラウザー楽器です。

- 6パートのミキサーと4つのパターン
- ベース・コードのピアノロールと音色調整
- セクションを並べる曲構成とWAV書き出し
- SIREN / AIR HORN / DUB SPACE / REWIND / THUNDER
- 曲ファイルと演奏を合わせるミックス録音
- プロジェクトJSONの保存・読み込み、PWA対応

## 4つのライブエフェクト
- **AIR HORN（エアホーン）**：サウンドシステムでおなじみの強烈な警笛音。「パーーッ！」と鳴らし、ドロップや盛り上がりを強調します。
- **DUB SPACE（ダブ・スペース）**：XYパッドで音の明るさや空間的なエフェクトをリアルタイムに操作。音が遠ざかったり漂ったりするダブらしい表現を楽しめます。
- **REWIND（リワインド）**：レコードを巻き戻すような「キュルルッ！」という効果音。「Pull Up」を思わせる演出で、曲そのものを巻き戻す機能ではありません。
- **THUNDER（サンダー）**：スプリングリバーブを揺らしたような、金属的な雷鳴の効果音。クラシックDUBならではの強烈なアクセントです。

## 使い方
PLAYでリズムを再生。ピアノロールで音符を編集し、曲構成のセクションにパターンを割り当てます。DUB SPACEでエコーを操り、REWINDをタップすると巻き戻し音が鳴ります。

ライブ操作を含む音声はMUSIC & RECで録音してください。曲構成のWAV書き出しはシーケンスを出力します。

## 実行
ビルド不要。Webサーバーでこのフォルダーを配信します。PWAにはHTTPSまたはlocalhostが必要です。

## 音源
REWINDは利用者から提供された参照録音の短い効果音を使用しています。音声素材に一括したオープンソースライセンスは付与していません。
